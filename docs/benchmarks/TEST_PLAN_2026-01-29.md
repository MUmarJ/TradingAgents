## Objective

Validate whether the 12-agent multi-agent architecture produces measurably better trading decisions than a single well-prompted agent across multiple model tiers, over 12 months of real market data.

## Bugs Fixed Before Testing

1. **Cross-contamination in ChromaDB memory** — Memories from ticker A were bleeding into ticker B's analysis. Fixed by scoping ChromaDB collection names with ticker prefix (e.g., `AAPL_bull_memory`).

2. **BUY bias (93% BUY, 0% SELL)** — Three root causes fixed:
   - Signal extraction word-counting fallback inflated BUY count. Replaced with `return "HOLD"` to trigger LLM fallback.
   - Bull researcher prompt contained prestige bias: "showing why the bull perspective holds stronger merit". Changed to neutral wording.
   - Risk manager prompt lacked structured output format. Added explicit `FINAL TRANSACTION PROPOSAL: **X** / CONFIDENCE: **0.X**` instruction.
   - Trader prompt used categorical confidence (LOW/MEDIUM/HIGH). Changed to numeric (0.0-1.0).

3. **Outcome validation** — Many outcomes had `entry_price=0.0` and `validated=false`. Added automatic market validation via yfinance when creating outcomes.

## Features Added

1. **Quantitative Guardrails**
   - Technical signal extraction (RSI, MACD, SMA positions) from market reports
   - Soft opinion: Structured "Technical Signals Summary" with conflict detection
   - Hard override: BUY -> HOLD only when RSI > 80 AND bearish MACD AND price below both 50/200 SMA (all conditions simultaneously)

2. **Transaction Cost Modeling**
   - Spread: 0.1% of position value
   - Slippage: 0.05% of position value
   - Applied to all non-HOLD trades (round-trip)

3. **Cost Tracking Fields**
   - `llm_calls`, `input_tokens`, `output_tokens`, `estimated_cost_usd` on TradeOutcome

4. **Confidence-Scaled Position Sizing**
   - `confidence_scaled_position()`: Size = portfolio * max_fraction * confidence
   - Available but not default (uses fixed $10K for baseline comparison)

5. **Resumable Backtest Harness**
   - JSON checkpoint system tracking per-task status (pending/running/completed/failed)
   - Auto-saves after every task
   - Survives API rate limits, network errors, process interruptions
   - Resume: `python -m cli.evaluate --resume`
   - Retry failed: `python -m cli.evaluate --resume RUN_ID --retry-failed`

## Execution Commands

```bash

  --start 2025-01-28 --end 2026-01-28 --interval monthly --articles-per-month 50

python -m cli.evaluate --compare bt_20260129_133950,bt_20260129_163016
```

## Success Criteria

1. **Decision distribution:** BUY < 80%, SELL > 5% (was: 93% BUY, 0% SELL)
2. **Confidence extraction:** >80% of outputs produce parseable confidence scores
3. **All outcomes validated:** 0 outcomes with `entry_price=0.0`
4. **No cross-contamination:** Each ticker's scoped memory is isolated
5. **Key question answered:** Does multi-agent beat single-agent over 12 months?

## Early Observations (Run 1, 42/216 tasks completed)

**Tickers completed:** RAPT (all 12 months), SUPN (2 months, in progress)

| Metric | multi_agent | single_deep | single_quick |
|--------|-------------|-------------|--------------|
| Accuracy | 21% (3/14) | 36% (5/14) | 7% (1/14) |
| BUY decisions | 0 | 0 | 0 |
| SELL decisions | 1 | 6 | 2 |
| HOLD decisions | 13 | 8 | 12 |
| Total P&L | $774.47 | $2,176.07 | $69.81 |

**Key findings so far:**
1. **BUY bias completely eliminated** — 0 BUY decisions across all strategies. Directionally correct for RAPT (declining biotech). May need calibration for stocks that should receive BUY signals.
2. **`single_deep` (gpt-5.1-codex-mini) outperforming** — 36% accuracy vs 21% multi-agent. More willing to call SELL when data supports it.
3. **Multi-agent HOLD bias** — The multi-agent system defaults to HOLD 93% of the time (13/14). The structured extraction may not be matching the risk judge's output format, causing the HOLD default + LLM fallback which also tends toward HOLD.
4. **Transaction costs working** — $15 cost per non-HOLD trade visible in P&L calculations.
5. **SUPN early results** — single_deep and single_quick both correctly called SELL on SUPN Feb 2025 ($+84.81 each).
